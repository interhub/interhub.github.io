# 🎨 visual-kit - рукописные SVG-ассеты бренда Степана

🖌️ Моно-линия, рука, чуть неровный штрих. Палитра ink/cream + терракота `#C8552B` / клай `#E0A24E` точечно.
🎯 Все линии на `stroke="currentColor"` - **цвет задаётся при вставке** (тёмная/светлая версии не нужны).
🚫 Без градиентов, без теней/glow, без холодных цветов, без эмодзи в кадре.
👁️ Общий превью-лист всех ассетов: `_preview.png`.
