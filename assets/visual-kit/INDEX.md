# 🎨 visual-kit v2 - рукописные SVG-ассеты бренда Степана

🖌️ Тёплый editorial-monoline в духе Claude. Уверенный живой штрих, насыщенные сценки с характером (не плоские глифы).
🎯 Все линии на `stroke="currentColor"` - **цвет задаётся при вставке**. Терракота `#C8552B` / клай `#E0A24E` - фирменный акцент (точечно, иногда одна залитая форма на сцену).
🚫 Без градиентов, теней/glow, холодных цветов, эмодзи в кадре.
🖌️ Все ассеты идут с фирменным рукописным rough-финишем (пресет E: R14 B2, scale-aware). Чистые исходники до rough - в `_clean/`.
👁️ Общий превью всех ассетов: `_preview.png`. Прошлая примитивная версия лежит в `_primitive-v1/`.
